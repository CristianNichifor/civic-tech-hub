Civic Tech Hub

Pure link directory. No shared code, no build step — just pointers to independent projects.

Director simplu de linkuri. Fără cod comun, fără build — doar trimiteri către proiecte independente.

  • Romania ReformsReforme România repo

    Simulators for Romanian public-policy reforms — deterministic, explainable, browser-only. Includes the pay (salarizare) and administrative-consolidation (administrativ) simulators.

    Simulatoare pentru reformele de politici publice din România — deterministe, explicabile, rulează integral în browser. Include simulatoarele de salarizare și de consolidare administrativă.

  • Legislative LinterLegislativ repo

    Linter for draft Romanian legislation: unfulfilled statutory deadlines, terminology drift, candidate contradictions — every finding carries its source article.

    Verificator pentru proiectele de legislație din România: termene legale neîndeplinite, derive terminologice, contradicții candidate — fiecare rezultat indică articolul sursă.

  • Open ProcurementAchiziții Deschise repo

    Open data on Romanian public procurement — comparable unit prices, OCDS format. 26.6M direct-acquisition records, queryable in-browser via DuckDB-Wasm.

    Date deschise despre achizițiile publice din România — prețuri unitare comparabile, format OCDS. 26,6 milioane de achiziții directe, interogabile direct în browser prin DuckDB-Wasm.

  • Digital Romania AtlasAtlas Digital România repo

    Maps Romania's digital-identity ecosystem against a proposed EUDI Wallet "digital backbone" — institutions, data flows, feature comparison, timeline.

    Cartografiază ecosistemul de identitate digitală al României comparativ cu un „backbone digital” propus pe baza EUDI Wallet — instituții, fluxuri de date, comparație de funcționalități, cronologie.

  • RO Intel Reform · Data FlowsReforma Informațiilor RO · Fluxuri de Date repo

    Interactive demo of current vs. target-state information flows between Romania's intelligence, oversight, judicial and civilian institutions.

    Demonstrație interactivă a fluxurilor de informații actuale față de starea-țintă propusă, între instituțiile de informații, control, justiție și cele civile din România.

  • USR Digital Platform WireframeMachetă Platformă Digitală USR repo

    Unofficial prototype for a rebuilt public site and member area — not an approved or connected service.

    Prototip neoficial pentru un site public și o zonă de membri regândite — nu este un serviciu aprobat sau conectat.

  • Civic UIUI Civic docs

    MIT-licensed React component library with opt-in themes, shared across the projects above.

    Bibliotecă de componente React licențiată MIT, cu teme opționale, folosită în comun de proiectele de mai sus.
